# Addon assets

This folder is merged into the game after the user-supplied `abc/` tree.

* `AVI/46_2.AVI` — missing IGLO photo supplied by the port.
* `OVR/2009_IGLO_hover.bmp` — IGLO letter-playground hover artwork.
* `WAV/46H.WAV` — IGLO hover cue.
* `MIDI/*.ogg` — the 16 original MIDI playlists rendered with FluidSynth.

The OGGs are generated by `tools/render_midi.py` from the user's own extracted
`abc/MIDI` files and a GM soundfont.  They are included here so the Android APK
has background music without shipping FluidSynth.  The original game content
is still copyrighted; do not redistribute a build containing the full `abc/`
tree without permission.
